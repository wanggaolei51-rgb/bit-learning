# BIT 词条规范 / BIT Vocabulary Standard

> 版本: 1.0 | 最后更新: 2026-10-02 | 状态: 生效中

---

## 一、九字段体例

每个词条必须包含以下 9 个字段：

| # | 字段 | 类型 | 说明 |
|---|---|---|---|
| 1 | `word` | string | 印尼语词条（主键） |
| 2 | `cn` | string | 中文释义 |
| 3 | `en` | string | 英文释义 |
| 4 | `root` | string | 词根（保守不拆，不确定标 `[待核实]`） |
| 5 | `forms[]` | array | 变形表（词缀变化） |
| 6 | `formsNote` | string | 变形规则说明 |
| 7 | `note` | string | 用法笔记 / 搭配说明 |
| 8 | `synonyms[]` | array | 同义词 |
| 9 | `antonyms[]` | array | 反义词 |
| 10 | `examples[]` | array | 例句（印尼语 + 中文翻译） |

## 二、生产流程

```
BIT 初稿生成 → BIO 审查定稿（R1-Rn 修订）→ RCO 审计 → 通过 → 部署
```

## 三、核心原则

1. **保守不拆词根**：不确定的词根标注 `[待核实]`，禁止编造
2. **印尼语纯度**：禁止方言混入（C5 要求）
3. **语境优先**：例句优先使用项目管理/商务/冶炼园区语境
4. **同词覆盖**：复习日重收同词 → bitVocabDB 覆盖更新为最新版（设计行为）
5. **勘误对账**：每次生产附词数勘误对账表（用户输入 vs 最终词条逐词映射）

## 四、弹窗展示规范（showBITInfo 四级回退）

```
bitVocabDB 精确命中 → 变形匹配 → 词根匹配 → 词缀剥离
```

展示内容：
- 🔄 变形表
- 🔗 同义词
- ↔️ 反义词
- 📝 例句
- 💡 用法笔记
