# BIT 词条规范 / BIT Vocabulary Standard

> 版本: 1.0 | 最后更新: 2026-10-02 | 状态: 生效中

---

## 一、九字段体例

每个词条必须包含以下 9 个字段：

| # | 字段 | 类型 | 说明 |
|---|---|---|---|
| 1 | `word` | string | 印尼语词条（主键） |
| 2 | `cn` | string | 中文释义 |
| 3 | `en` | string | 英文释义 |
| 4 | `root` | string | 词根（保守不拆，不确定标 `[待核实]`） |
| 5 | `forms[]` | array | 变形表（词缀变化） |
| 6 | `formsNote` | string | 变形规则说明 |
| 7 | `note` | string | 用法笔记 / 搭配说明 |
| 8 | `synonyms[]` | array | 同义词 |
| 9 | `antonyms[]` | array | 反义词 |
| 10 | `examples[]` | array | 例句（印尼语 + 中文翻译） |

## 二、生产流程

```
词元清洗（去重+大写归一）→ 生成词条（≤15词主session / >30词 sub-agent并行）
→ JSON 批次落盘 → 合并为 BIT 定稿 md → BIO 审查定稿（R1-Rn 修订）
→ RCO 审计 → 通过 → 部署
```

### ⚠️ 变形表格格式硬性要求（10/10 事故教训）

`forms` 字段在 BIT 定稿 md 中**必须用表格格式**写入，禁止简化为顿号分隔列表：

```markdown
❌ 错误：- **变形**: membantah、dibantah、pembantaan、bantahan
✅ 正确：
- **变形**:

| 形式 | 词性 | 含义 |
|------|------|------|
| membantah | 动词 | 反驳（meN- 主动） |
| dibantah | 被动动词 | 被反驳（di- 被动） |
```

**原因**：`md_to_dailynote.py` 解析器仅识别表格行（`|...|`）为 forms 数据。列表格式会被当作 `formsNote` 文本处理，导致 `forms=[]`，BIT 弹窗变形区域显示空白。

### 大批量任务并行规则（M2 v2.4 同步）
- 词元 >30 时必须拆 sub-agent 并行生成，按 20 词/批
- 每个 sub-agent 输出 JSON 到 `/tmp/bit_<date>_batch<N>.json`
- 主 session 只做合并和部署编排，不直接生成大量词条

## 三、核心原则

1. **保守不拆词根**：不确定的词根标注 `[待核实]`，禁止编造
2. **印尼语纯度**：禁止方言混入（C5 要求）
3. **语境优先**：例句优先使用项目管理/商务/冶炼园区语境
4. **同词覆盖**：复习日重收同词 → bitVocabDB 覆盖更新为最新版（设计行为）
5. **勘误对账**：每次生产附词数勘误对账表（用户输入 vs 最终词条逐词映射）

## 四、生词查询双库同步条款（V4.44.0 新增，RCO 同类问题 N 次直报）

### 规则
**所有词查询入口必须双库查询（vocabDB + bitVocabDB），bitVocabDB 优先。**

### 背景教训
- 10/19 用户报告：短文中点击生词有 BIT 弹窗，但翻译页搜索不到、生词本翻译不准
- 根因：三个入口各自只查单库，BIT 笔记词（全在 bitVocabDB）在这些入口被当"未收录"处理 → 走在线翻译（不准）→ 不准的翻译还自动写入生词本

### 双库查询清单（每次版本更新必须逐一检查）
| 入口 | 函数 | 要求 |
|---|---|---|
| 翻译页搜索 | `doTranslate` | vocabDB 未命中 → bitVocabDB → 词缀拆解 → 在线翻译 |
| 短文/对话点击 | `showWordPopup` | vocabDB 未命中 + bitVocabDB 命中 → 直接 `showBITInfo` |
| 场景 tooltip | `showTip` | 同 showWordPopup（V4.39.4 已接入） |
| 生词本同步 | `renderWBList` 同步循环 | vocabDB 同步后必须再跑 bitVocabDB 同步分支 |
| 课程核心词卡 | `renderTopicDetail` 两处 | V4.43.1 已接入（bitVocabDB 双库分支） |

### 检查口诀
每次版本部署前自问：**新收录的 BIT 词条在以上 5 个入口都能查到吗？**

### 同步覆盖更新规则
复习日重收同词 → bitVocabDB 覆盖更新 → `renderWBList` 下次打开自动把新翻译同步进生词本（V4.44.0 起）。
