# C5 课程生成策略 / C5 Course Generation Strategy

> 版本: 2.2 | 最后更新: 2026-10-16 | 状态: 生效中

---

## 一、规则A — 每日复习
每天课程开始前，自动生成**前一天课程的 C4_MAP 总结**，可折叠展开。

## 二、规则B — 新话题衔接
新话题第一天，自动生成**前一话题全部天数的总结**思维导图，可折叠展开。

## 三、规则C — 核心词汇（★ 2026-10-02 强化）

### C.1 数量要求
每次生成的新话题课程中，第一天核心词汇 **≥20个**。

### C.2 选词标准
所选词汇需**高频、常用或有代表性**。

### C.3 来源强制条款（2026-10-02 新增）
> **核心词必须从当前话题课程资料（`topic.vocab`）中提炼。**
> **禁止使用 fallback 兜底词表替代。**

- Day1 词卡渲染逻辑：`topic.vocab.slice(0, 30)` → vocabDB 匹配 → 渲染词卡
- 当 `topic.vocab` 数据异常（如嵌套错误导致 length < 5）时，代码会 fallback 到硬编码兜底词表 `fb{}`，这是 **BUG 而非特性**
- **教训 V4.39.6**：三个新话题（environmental_compliance / supply_chain / emergency_response）的 `topic.vocab` 被写成双层嵌套 `[[...]]`，运行时 `length===1` 触发 fallback，Day1 词卡显示"见面问候"词而非课程核心词

### C.4 BIT 弹窗接入
- 核心词卡点击 **必须** 打开 BIT 标准详解弹窗（`showBITInfo`）
- 路由：`showTip()` → 同时查 `vocabDB`（transform/example/synonym 字段）和 `bitVocabDB`（O(1) 命中即走 showBITInfo 四级回退链）
- 四级回退链：bitVocabDB 精确词 → 变形匹配 → 词根匹配 → 词缀剥离
- **V4.39.4 已接入**：覆盖 10/2-10/10 三话题全部 118 核心词

### C.5 核心词渲染双库查询（★ 2026-10-16 新增，V4.43.1）
> **Day1 词卡渲染必须同时查询 `vocabDB` 和 `bitVocabDB` 两个库。**
> **禁止只查 `vocabDB` 导致 bitVocabDB 词条空白。**

- 根因（V4.43.0 UKBI 课）：Day1 词卡渲染代码 `Object.keys(vocabDB).find(...)` 只查五字段库，UKBI 38 个核心词全写入九字段 `bitVocabDB`，导致词卡区域空白
- 修复：两处 `keyWords.forEach` 增加 `else if` 分支查 `bitVocabDB`，命中后渲染词卡 + 点击走 `showBITInfo()`
- 同时取消 `slice(0, 30)` 截断，全量展示 `topic.vocab`
- 规则：**新增话题课程时，核心词写入 `bitVocabDB` 后必须验证 Day1 词卡渲染是否双库可查**

## 四、规则D — 场景对话
- 每话题 3 个场景
- 每场景 10-20 句对话
- 对话内容优先项目管理/商务/冶炼园区语境

## 五、规则E — 课时测试
- 每话题 15 题测试题
- 含答案解析

## 六、词汇量约束
- 每话题核心词汇 20-40 个
- C5 精简标准：38-40 词/话题（V4.38.3 合规）

## 七、词缀玫瑰图（★ 2026-10-16 新增，V4.43.1）

### 7.1 功能定义
每日课程页"昨日复习"下方自动附加"词缀玫瑰图"入口卡片（日期 ≥ 2026-10-17 生效）。

### 7.2 技术方案
- 30 词缀 6 类（前缀/后缀/环绕/外来/中缀/语助词）交互可视化
- `AFFIX_ROSE_HTML` 常量内嵌完整单文件 HTML（44KB）
- `iframe srcdoc` 渲染，完全隔离样式/脚本，不与主页面冲突
- `</script>` 在 JS 字符串中必须转义为 `<\/script>`（V4.43.1 教训：内嵌 HTML 含 script 标签导致语法解析失败）
- 路由：`navigate('affixRose')` → `renderAffixRose(c)` → iframe.srcdoc 注入

### 7.3 展示规则
- 出现位置：C5 复习模块末尾（"昨日复习"折叠区块之后）
- 出现条件：`ds >= '2026-10-17'` 的日期页
- 交互：点击卡片 → navigate 跳转玫瑰图全屏页
