# RCO 审计策略 / RCO Audit Protocol

> 版本: 1.0 | 最后更新: 2026-10-02 | 状态: 生效中

---

## 一、审计类型

### A1 — 抽样审计
- 随机抽取 10-20% 词条进行人工准确性检查
- 类问题：拼写错误、编造词根、方言混入、中译偏差

### A3 — 词级三方对账
- **用户输入词元 vs 任务词表 vs 最终词条** 逐词对齐
- 去重统计唯一词数
- 产出对账表（附录一逐条映射）
- **教训 V4.34.0**：23→26 词对账纠正，主调度任务书误写词数

## 二、处置流程

```
WARN（警告）→ 修复 → 复审 → APPROVE（通过）
FAIL（失败）→ 阻断上线 → 全面修复 → 重审
```

### WARN 拦截项
- 拼写错误（如 memroyeksikan→memproyeksikan）
- 词数不一致
- 词表来源不明
- 例句不含目标词条词

### 同类问题 N 次直报
同一类问题出现 N 次 → 不重复 WARN，直接上报指挥官决策。
