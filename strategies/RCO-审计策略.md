> 版本: 1.0 | 最后更新: 2026-10-02 | 状态: 生效中

---

## 一、审计类型

### A1 — 抽样审计
- 随机抽取 10-20% 词条进行人工准确性检查
- 类问题：拼写错误、编造词根、方言混入、中译偏差

### A3 — 词级三方对账
- **用户输入词元 vs 任务词表 vs 最终词条** 逐词对齐
- 去重统计唯一词数
- 产出对账表（附录一逐条映射）
- **教训 V4.34.0**：23→26 词对账纠正，主调度任务书误写词数

## 二、处置流程

```
WARN（警告）→ 修复 → 复审 → APPROVE（通过）
FAIL（失败）→ 阻断上线 → 全面修复 → 重审
```

### WARN 拦截项
- 拼写错误（如 memroyeksikan→memproyeksikan）
- 词数不一致
- 词表来源不明
- 例句不含目标词条词

### 同类问题 N 次直报
同一类问题出现 N 次 → 不重复 WARN，直接上报指挥官决策。

### 教学材料语言校对（A6,V4.48.3 起强制执行）

短文/场景对话/例句随课程上线时，RCO 必须逐句通读印尼语原文，查 6 项：

1. **拼写**：数字词（puluh/ratus/ribu）、双写、形近误植（pulik/yaya 类）
2. **借用词**：engineer/manager 类英语借词 → 正文换 insinyur/manajer（markir 词条库保留作词汇教学，范文用 tandai/penandaan）
3. **事实一致性**：分数段/等级名/时间流程数字，**以站内已上线课程数据为唯一基准**（ukbi_drill 事故：总分 600 实际 800、480=madya bawah 实为 Semenjana、7 工作日实为 14）
4. **等级名查表**：UKBI 七级 = Istimewa 725-800 / Sangat Unggul 641-724 / Unggul 578-640 / Madya 482-577 / Semenjana 405-481 / Marginal 326-404 / Terbatas 251-325，不存在 madya bawah
5. **语法细节**：antara 原则上只接两项，三项+用 di antara；专名大写（Mongolia Dalam = 内蒙古）
6. **翻译对应**：新写中文翻译必须与勘误后印尼语原文逐段对应（先勘误，后翻译）

另两条配套断言：
- **短文 trans 完整性**：渲染 `${sp.trans||'翻译加载中...'}` 静默占位，上线前全量断言每篇 speech 有非空 trans（V4.48.3 事故：15 篇缺失，topic24/25 老课也中招）
- **词义高亮双库**：bindWordTransHighlight 查词必须 vocabDB+bitVocabDB 双库，cn 多义项拆分匹配，移动端点击触发
