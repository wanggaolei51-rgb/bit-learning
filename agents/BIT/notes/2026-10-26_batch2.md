# 2026-10-26 每日笔记批次二（20词）

### 22. makanya-sebabnya-oleh-karena-itu
- **中文**: 所以；因为；因此；所以
- **English**: so; because; therefore; that's why
- **词根**: karena（因为）→ oleh karena itu（因此）；sebab（原因）→ sebabnya（因为）；maka（于是）→ makanya（所以）
- **变形**: 无词缀变形
- **词汇注释**: 四个因果连词构成一条学习链：karena（因为，最中性通用，口语书面皆可）；sebabnya（"因为"，sebab 名词+nya 口语化，日常对话）；oleh karena itu（"因此"，正式书面，公函/报告/考试写作首选）；makanya（"所以"，最口语随意）。语域正式度排序：oleh karena itu > karena > sebabnya ≈ makanya。UKBI 写作优先用 oleh karena itu 与 karena。
- **同义词**: karena itu、sehingga、oleh sebab itu
- **反义词**: —
- 面试复盘: *Oleh karena itu, saya memutuskan untuk mengambil kursus persiapan UKBI.* 因此，我决定参加 UKBI 备考课程。
- 考前讨论: *Makanya, kamu harus tidur lebih awal sebelum hari ujian.* 所以，考试前一天你必须早点睡觉。

### 23. keputusan
- **中文**: 决定；决策
- **English**: decision
- **词根**: putus（断开、裁决）→ memutuskan（决定）→ keputusan（决定，名词）
- **变形**:

  | 形式 | 词性 | 含义 |
  | --- | --- | --- |
  | memutuskan | 动词 | 决定 |
  | keputusan | 名词 | 决定、决策 |
  | terputus | 形容词 | 中断的 |
  | pemutus | 名词 | 决策者；断路器 |

- **词汇注释**: putus（切断）+ ke-an 名词化。"作出决定" = mengambil/membuat keputusan；"最终决定" = keputusan final。项目管理中 change decision（变更决策）高频出现。
- **同义词**: ketetapan、resolusi、kehendak
- **反义词**: keraguan、penundaan
- 项目管理: *Manajer proyek mengambil keputusan untuk menunda pengiriman peralatan.* 项目经理作出推迟设备发货的决定。
- 备考计划: *Keputusan saya mengikuti UKBI sudah matang sejak bulan lalu.* 我参加 UKBI 的决定上个月就已考虑成熟。

### 24. membedakan
- **中文**: 区分；辨别
- **English**: to differentiate; to distinguish
- **词根**: beda（不同）→ membedakan（区分、使有别）
- **变形**:

  | 形式 | 词性 | 含义 |
  | --- | --- | --- |
  | beda | 名词/形容词 | 不同、差别 |

  | membedakan | 动词 | 区分、辨别 |
  | perbedaan | 名词 | 区别、差异 |

- **词汇注释**: me- + beda + -kan 使动词，指在多者之间辨别差异。UKBI 阅读常考 perbedaan pendapat（意见分歧）辨析题。
- **同义词**: memisahkan、memperbedakan
- **反义词**: menyamakan、mencampurkan
- 面试准备: *Kamu harus bisa membedakan pertanyaan tentang pengalaman dan pertanyaan hipotetis.* 你必须能区分经验类问题和假设性问题。

### 25. perencanaan

### 27. melampirkannya
- **中文**: 附上它；把它附在文件后
- **English**: to attach it (to a document)
- **词根**: lampir（附带）→ lampiran（附件）→ melampirkan（附上）→ melampirkannya（把它附上）
- **变形**:

  | 形式 | 词性 | 含义 |
  | --- | --- | --- |
  | lampiran | 名词 | 附件 |
  | melampirkan | 动词 | 附上、随附 |
  | melampirkannya | 动词（代词化） | 把它附上 |
  | terlampir | 形容词 | 随附的 |

- **词汇注释**: me-…-kan + 代词 -nya。-nya 回指前文提到的那份文件。邮件高频句：Saya melampirkan CV saya（我随附简历）；CV terlampir（简历见附件）。

- **反义词**: melepaskannya、mencopotnya

- 文件往来: *Lampirannya sudah saya periksa. Silakan melampirkannya kembali ke surat resmi.* 附件我已检查。请把它附回正式函件。

### 28. mengikut-sertakan
- **中文**: 使参与；把……列入；让……加入
- **English**: to include (someone); to involve
- **词根**: ikut（跟随、参加）→ mengikuti（参加）→ mengikut-sertakan（使参与）
- **变形**:

  | 形式 | 词性 | 含义 |
  | --- | --- | --- |
  | ikut | 动词 | 跟随、参加 |
  | mengikuti | 动词 | 参加、遵循 |
  | mengikut-sertakan | 动词 | 使参与、列入 |
  | diikut-sertakan | 动词被动 | 被纳入 |
  | pengikut | 名词 | 追随者 |

- **词汇注释**: ikut + sertakan 复合派生，强调"人"的参与（比 mencakup 更突出把某方拉进来）。标准拼写为连写 mengikutsertakan（KBBI），连字符形式 mengikut-sertakan 为旧式/强调写法，本键按词表保留连字符形式。
- **同义词**: menyertakan、melibatkan、mencakup
- **反义词**: mengecualikan、memisahkan
- 会议纪要: *Kami mengikut-sertakan tim K3 dalam rapat evaluasi mingguan.* 我们让 K3 安全团队参加每周评估会议。
- 项目启动: *Semua pemangku kepentingan diikut-sertakan sejak tahap desain.* 所有利益相关方从设计阶段起就被纳入。

### 31. intinya
- **中文**: 关键是；总之；要点是
- **English**: the point is; in short; essentially
- **词根**: inti（核心、要点）→ intinya（其要点、说白了）
- **变形**:

  | 形式 | 词性 | 含义 |
  | --- | --- | --- |
  | inti | 名词 | 核心、要点 |
  | intinya | 副词/习语 | 关键是、总之 |
  | berinti | 形容词 | 有核心的 |

- **词汇注释**: inti + 代词 -nya，口语高频总结词，长话短说时用 "Intinya, ..."（说白了/总之）。正式写作可用 pokoknya 或 ringkasnya 替代。物理上 inti 也指"核"（inti atom 原子核）。
- **同义词**: pokoknya、ringkasnya
- **反义词**: —
- 面试复盘: *Intinya, pewawancara ingin melihat sikap profesionalmu.* 关键是，面试官想看你的职业态度。
- 会议总结: *Rapat berjalan dua jam. Intinya, ada tiga tindak lanjut.* 会议开了两小时。总之，有三项后续行动。

### 32. apapun

- **词根**: apa（什么）+ pun（也、无论）→ apapun（无论什么）

- **反义词**: —

- 备考心态: *Jangan panik menghadapi soal apapun yang belum kamu pelajari.* 面对任何没学过的题目都不要慌。

### 40. tahan
- **中文**: 屏住；忍住；坚持；抵挡
- **English**: to hold; to endure; to restrain
- **词根**: tahan（承受、抵抗，词根本身）
- **变形**:

  | 形式 | 词性 | 含义 |
  | --- | --- | --- |
  | tahan | 动词 | 屏住、忍住 |
  | bertahan | 动词 | 坚持、维持 |
  | menahan | 动词 | 忍住、阻挡 |
  | tahanan | 名词 | 拘留者、囚犯 |
  | tertahan | 形容词 | 被阻挡的 |
  | ketahanan | 名词 | 耐力、韧性 |

- **词汇注释**: 呼吸口令第二步：tahan napas empat hitungan（屏息数四下）。日常高频：menahan tawa（忍笑）、bertahan hidup（生存）、bertahan dalam tekanan（抗压）。ketahanan nasional = 国家韧性。
- **同义词**: bertahan、menahan
- **反义词**: menyerah、melepaskan
- 呼吸练习: *Setelah menarik napas, tahan selama empat hitungan sebelum menghembuskan.* 吸气后，屏住四拍再呼出。
- 谈判场景: *Dia mampu menahan emosi saat negosiasi berjalan alot.* 谈判艰难时他能控制住情绪。

### 41. hembuskan-perlahan
- **中文**: 慢慢呼出（呼吸练习口令）
- **English**: exhale slowly (breathing exercise cue)
- **词根**: embus/hembus（呼气）→ menghembuskan（呼出）→ hembuskan（呼出，祈使式）；perlahan（慢慢地）
- **变形**:

  | 形式 | 词性 | 含义 |
  | --- | --- | --- |
  | embus | 名词 | 呼气 |
  | menghembuskan | 动词 | 呼出 |
  | hembuskan | 祈使句 | 呼出吧 |
  | perlahan | 副词 | 慢慢地 |
  | perlahan-lahan | 副词 | 缓缓地 |

- **词汇注释**: 复合口令键：hembuskan perlahan（慢慢呼出）。4-4-4 呼吸法第三步。hembuskan 为 menghembuskan 的祈使缩略（口令常用），完整说法：menghembuskan napas secara perlahan。工业场景亦指呼气检测（menghembuskan napas ke alat tester）。
- **同义词**: —
- **反义词**: —
- 呼吸练习: *Tarik napas, tahan, lalu hembuskan perlahan melalui mulut.* 吸气，屏住，然后慢慢从嘴里呼出。
- 下班放松: *Setelah shift malam, hembuskan perlahan sambil membayangkan ketegangan keluar.* 下夜班后，慢慢呼气，想象压力随之排出。
